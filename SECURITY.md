# Security

This project is a local retrieval library. It does not connect to Zelvora services and does not require credentials.

Do not commit customer documents, secrets, access tokens, or private evaluation data. When the GitHub repository is attached, report vulnerabilities privately through GitHub Security Advisories rather than a public issue.

The included `HashEmbeddingProvider` is deterministic example code. It is not a semantic model and should not be used as a security or quality boundary.
